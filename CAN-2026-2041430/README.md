# BBX-001 preserved crash inputs

Malformed `.rpm` files triggering the out-of-bounds read in BusyBox 1.38.0
[archival/rpm.c](../../../source/busybox/archival/rpm.c) (`G.mapsize` recorded at line 148,
never consulted). Generated by
[harnesses/busybox/poc_bbx001_gen_rpm.py](../../../harnesses/busybox/poc_bbx001_gen_rpm.py).

| File | Size | md5 | Applet | Faulting frame |
|:---|:---|:---|:---|:---|
| `bbx001_pathA_rpm2cpio.rpm` | 144 B | `c8e734a24a49b0fbf08863991ac5c304` | `rpm2cpio` | `strcmp` ← `rpm2cpio_main` rpm.c:539 |
| `bbx001_pathB_rpm_qpi.rpm` | 144 B | `d68fdff40f0df3369b45ab7af00b2039` | `rpm -qpi` | `internal_strlen` ← `printf` ← `rpm_main` rpm.c:431 |
| `bbx001_pathC_rpm_qpl.rpm` | 160 B | `2679c8be8c57138c1e5cac30355369d0` | `rpm -qpl` | `rpm_getint` rpm.c:203 |
| `bbx001_pathD_rpm_install.rpm` | 192 B | `8a0b2a15921b9d5334c4a48c41ee6137` | `rpm -i` | `rpm_getint` rpm.c:203 |
| `bbx001_all_paths.rpm` | 224 B | `d6957fa576424eb94f2b05ea8a759bf7` | all | trips every sink above |
| `bbx001_leak_declared_store.rpm` | 171 B | `6bfb72d6868106498c35c67d82aa6195` | `rpm -qpi` | **no crash** — leaks OOB bytes to stdout |

All five crashers set an index-entry `offset = 0x40000000` (~1 GiB) against a 4 KiB mapping.
The leak input instead uses `offset = 0` with `header.size = 0`, so the read lands on file bytes
the header does not claim — demonstrating the information-disclosure impact without a fault.

## Reproduce

```bash
# All paths at once, with ASan frames resolved to file:line:
../../harnesses/busybox/run_bbx001_repro.sh

# Single path:
ASAN_OPTIONS=detect_leaks=0 ../../../targets/busybox/build_asan/busybox \
    rpm -qpl bbx001_pathC_rpm_qpl.rpm
```

Expected for the crashers: exit code 1 and
`AddressSanitizer: SEGV ... The signal is caused by a READ memory access.`
